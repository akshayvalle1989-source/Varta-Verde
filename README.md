## About

Vartha Verde is an intelligent web-based platform designed to provide personalized agricultural guidance to smallholder Indian farmers. Using AI technology, it analyzes soil conditions, local climate, and crop-specific data to offer tailored recommendations.

### Key Features
- 🤖 *AI-Powered Recommendations* - Get personalized farming advice based on your land
- 🌍 *Climate & Soil Analysis* - Real-time climate and soil-specific guidance
- 🌱 *Crop Selection* - Best crops for your region and soil type
- 📊 *Data-Driven Insights* - Evidence-based agricultural recommendations
- 💬 *Live AI Assistant (Veda Verde)* - Chat with an AI farming expert
